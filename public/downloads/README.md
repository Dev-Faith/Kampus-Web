# Kampus Mobile App Downloads Directory

Place your compiled React Native / Expo Android APK file here as:
`kampus-student.apk`

Once placed, it will be automatically downloadable at:
`/downloads/kampus-student.apk`

Alternatively, you can configure an external cloud release URL (e.g. S3, GitHub Release, or Expo EAS) via:
`NEXT_PUBLIC_APP_APK_URL=https://...` in `.env.local`
